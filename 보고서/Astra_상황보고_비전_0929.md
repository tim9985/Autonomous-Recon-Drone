# 비전 상황 보고 — 사람 탐지 AP50 0.80 을 어떻게 넘길까

> 자율 정찰 드론 관제 시스템 · 비전 파트 · 2026-09-29 · 모든 수치는 실측 (장소 분리 평가 · 95 % 블록 부트스트랩)

## 1. 과업과 제약

| 항목 | 값 |
|---|---|
| 입력 → 출력 | 드론 영상 1920×1080 → 사람 박스 (1클래스 · 서/앉/누움 · 가림 포함) → 지도 좌표 |
| 운용 | 짐벌 하향 **60°** · 고도 16~30 m · 88° 렌즈 · 사람 긴 변 **약 36~94 px** |
| 합격 기준 (NFR-V03) | **AP50 ≥ 0.80 · 학습과 장소가 겹치지 않는 평가** · 재현율 우선 (미탐 > 오탐) |
| 추론 | YOLO11m · 1280×720 타일 4장 (50 % 겹침) · NMS 0.6 · TensorRT FP16 **18.9 ms** (기준 ≤ 30 ms · 3090) |
| 학습 자원 | RTX 3090 1대 · 30 에폭 1회 ≈ 9 h · 운용 GPU 는 4080 SUPER |

## 3. 해 본 것 — 먹힌 것과 안 먹힌 것

| ✅ 먹힘 | ❌ 효과 없음 / 역효과 |
|---|---|
| 60° 비스듬 데이터 (+30~40 %p) · 야생 지형 데이터 (+6 %p) | NWD 손실 (−2.4 %p) · P2 머리 (±0) · 11l (지연 초과 · 가림 지형에서 짐) |
| 같은 설정 2회 → 가중치 평균 (+1.6~2.2 %p) | 60 에폭 (val ↑ · test_obl −4.0 %p) · NII-CU 추가 (±0) |
| 사람 크기 31~94 px 로 크롭 학습 | 3개 수프 (BN 통계 붕괴) · BN 재계산 (박스만 넓어짐) |
| 🔄 NOMAD 가림·누움 부분집합 (v9) — **누움 재현율 0.36 → 0.49** · 전체 AP 는 −1~2 %p · 2회 수프 판정 오늘 밤 | |

- 같은 설정 반복 간 흔들림이 **1.3~3.4 %p** → 한 번 학습으로는 2 %p 차이를 못 가린다 (그래서 설정당 2회 + 수프)

## 4. 어디서 새는가 (test_obl · test_v2 오류 분해)

| 원인 | 크기 |
|---|---|
| **박스 모양 차이** (찾았지만 IoU < 0.5) | test_obl AP30 **0.845** ↔ AP50 0.633 → **약 22 %p** · 우리 박스가 정답보다 좁음 (너비비 0.69 → 수프 0.90) |

| 한국 산림 60° 영상 | 공개 데이터에 사실상 없음 → **10/15~ 첫 비행 후 자체 촬영** 계획 |

## 5. 여쭤보고 싶은 것

1. **판정셋**: 0.80 을 test_obl (라벨 습관이 다른 외부 셋) 로 판정하는 것이 맞나? 박스 기준 차이 22 %p 를 어떻게 다루는 게 정직한가 (IoU 0.3 병기 · 라벨 규약 맞춘 재라벨 · 자체 촬영 test_own 을 공식 판정셋으로)
2. **가림 · 누움**: 데이터 추가 (v9) 외에 짧은 기간에 효과가 큰 방법이 있나 — 가림 증강 (나뭇잎 조각 덮기) · 합성 (UE 시뮬레이터) · 가짜 라벨 자기학습 · 여러 프레임 (추적) 결합 중 우선순위
3. **자체 촬영**: 몇 장 · 몇 장소면 0.80 에 가까워지나 · 기존 모델 이어 학습 vs 처음부터 · 라벨 규약 (박스 너비 · 가림 사람 포함 기준)
4. **모델 쪽**: 입력 해상도 · 타일 · 모델 크기에서 30 ms 안에 남은 여지가 있나 (4080 SUPER 기준)
