# ERD 18개 검증 — 줄여도 놓치는 것 없나

> 대상: 제안 18개 (`ERD/drone_18.sql`) ↔ 기준: **SRS v1.7** (유즈케이스 73 · NFR · EX · 상태 규칙 · 인수시험) + **SDD v1.2 옛 ERD** (54개 · 컬럼 707 · 관계 169)
> 방법: 18개 스키마를 코드로 정의하고 아래 네 가지를 **스크립트로 자동 대조** — 없는 컬럼을 가리키면 오류로 잡힌다 · 2026-09-29

## 결론

- **SRS 가 저장하라는 것 96항목 — 전부 18개 안에 있다** (유즈케이스 73/73 · 없는 컬럼 참조 0)
- **옛 컬럼 707개 — 전부 갈 곳이 정해졌다** (못 옮긴 컬럼 0) · 버리는 것은 **GRACE 연구용 32개뿐**
- **옛 관계 169개 — 중앙 DB 안에서 끊기는 것 없음** · 25개는 JSON 안 참조로 바뀌어 DB 대신 앱이 검사 · 20개는 중앙 DB 에서 빠지는 테이블 5개(Pi 로컬 3 · GRACE 2)와 함께 빠짐
- 오히려 **옛 ERD 에 전용 칸이 없던 SRS 항목 6개**를 새로 채웠다 (3절)
