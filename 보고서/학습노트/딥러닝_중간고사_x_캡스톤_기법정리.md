## 1. 머신러닝 개요 (01-2)

### 1-1. 4가지 구성 요소 ★★ — 데이터 · 모델 · 손실 · 최적화

| 구성 요소 | 우리 프로젝트 |
|---|---|
| 데이터 | 공개 드론 데이터 10종 · **18,601장** (1280×720 조각) · 라벨 = 사람 박스 |
| 모델 | **YOLO11m** (CNN · 파라미터 2,010만) |
| 손실 함수 | 박스 위치 (CIoU + DFL) + 사람인지 (이진 교차 엔트로피) |
| 최적화 | **SGD + 모멘텀 0.937** · 학습률 0.01 · 가중치 감쇠 0.0005 |

### 1-2. 학습의 종류 · 예측 과제 4분면 ★★

| 강의 | 우리 |
|---|---|
| 지도학습 · 이산 = **분류** | 이 박스가 「사람」 인가 (1클래스) · 자세 (누움 / 앉음 / 서기) 확률 |
| 지도학습 · 연속 = **회귀** | 박스의 위치 · 크기 (x, y, 폭, 높이) 를 숫자로 맞힘 → **물체 탐지 = 분류 + 회귀** |
| 비지도 · 이산 = **군집** | 같은 사람의 탐지들을 하나의 「후보」 로 묶기 (위치 · 겹침 기준) · 색 계획 초안의 k-means |
| 비지도 · 연속 = 차원축소 | (직접 사용은 없음) · SigLIP · DINOv2 같은 큰 모델의 「특징 벡터」 를 색 · 외형 비교에 씀 |

### 1-3. Training vs Testing · IID ★ — 우리 프로젝트의 가장 큰 교훈

- 강의: 학습 데이터와 테스트 데이터는 **같은 분포 (IID)** 에서 나왔다고 가정
- 우리: 실제 운용 장소 (한국 산지) 는 학습 데이터에 없다 → **IID 가 깨진다**
  - 처음 모델: 학습과 **같은 장소**로 평가 AP50 **0.86** ↔ **처음 보는 장소** 0.22
  - 그래서 평가는 **학습에 쓰지 않은 장소**로만 한다 (장소 분리) — 숲 · 비스듬 · 한국 평가셋 3개
- 시험 포인트: 「테스트 성능이 높은데 실전에서 낮다」 → 학습 · 테스트가 같은 분포여서 (외운 것) — 우리 사례로 설명 가능

## 2. 인공신경망 (02)

### 2-1. 퍼셉트론 · MLP · 활성 함수 ★★

| 강의 | 우리 (YOLO11) |
|---|---|
| 계단 → 로지스틱 (시그모이드) · tanh · **ReLU** | 은닉층 활성 함수 = **SiLU** (= x · sigmoid(x) · ReLU 를 부드럽게 만든 것 · 0 근처에서도 기울기가 있음) |
| 이진 출력 = 로지스틱 · 다중 출력 = softmax | 「사람이냐」 = **시그모이드 + 이진 교차 엔트로피** (클래스가 1개라 softmax 대신) |
| 퍼셉트론은 XOR 못 풂 → 층을 쌓아 공간 변환 | 자세 판정은 **로지스틱 회귀 하나** (박스 세로/가로 비 · 크기 2개 입력 → 3자세 확률) = 가장 간단한 신경망 |

### 2-2. 경사하강법 · 미니배치 · 역전파 ★★★

| 강의 | 우리 학습 설정 |
|---|---|
| 학습률 크면 발산 · 작으면 느림 | 시작 학습률 **0.01** → 끝에서 0.0001 (lrf 0.01 배) 로 줄여 감 |
| 배치 / SGD / **미니배치** | **미니배치 8장** (1280 px 큰 그림이라 GPU 메모리 24 GB 에 8장) |
| 처음부터 큰 학습률은 위험 | **warmup 3 에폭** — 처음 3 에폭은 학습률을 0 에서 천천히 올림 (실제로 초반 2~4 에폭 점수가 잠깐 떨어지는 게 정상) |
| 역전파 = 연쇄 규칙으로 기울기 | PyTorch autograd 가 자동 (ultralytics 가 `loss.backward()` · `optimizer.step()`) |

### 2-3. 옵티마이저 ★★★

| 강의 | 우리 |
|---|---|
| SGD → **모멘텀** (관성) | **SGD + 모멘텀 0.937** — 탐지 학습에서 일반화가 잘 돼 YOLO 기본값 |
| AdaGrad · RMSprop · **Adam** (적응적 학습률) | Adam 계열 (AdamW) 은 짧은 학습에 ultralytics 가 자동으로 고르기도 함 · 우리는 SGD 로 고정 |

### 2-4. 과소적합 vs 과잉적합 ★★ — **우리 실제 사례**

- **60 에폭 실험 (09-29)**: 30 에폭 → 60 에폭으로 늘렸더니
  - 검증 (val) 점수 mAP50-95 **0.424 → 0.441 (올라감)**
  - 처음 보는 장소 평가 (비스듬) **−4.0 %p (떨어짐)** → 학습 데이터 장소를 외운 **과잉적합**
- v12 에서 낮은 학습률로 30 에폭 더 이어도 비스듬 −2.4 · 숲 −1.9 %p → **30 에폭 고정**
- 교훈: 검증셋이 학습과 비슷하면 과적합을 못 잡는다 → 검증도 장소가 겹치지 않게 다시 만듦
- 시험 포인트 (04 「과적합 판단 4가지 패턴」): 학습 손실 ↓ · 검증 손실 ↑ 가 갈라지면 과적합

### 2-5. 규제 (Regularization) ★★★ — 「큰 신경망 + 규제」

| 강의 | 우리 설정 | 왜 |
|---|---|---|
| ① **데이터 증대** | **모자이크** (4장을 이어 붙임) · 크기 ±30 % (`scale 0.3`) · 이동 ±15 % · 회전 ±10° · **좌우 뒤집기 50 %** · **상하 뒤집기 0 %** · 색조 · 채도 · 밝기 흔들기 | 45° 비스듬 화면은 위 = 먼 곳 · 아래 = 가까운 곳이라 상하 뒤집으면 현실에 없는 그림 → 끔 · 짐벌이 기울기를 잡아 줘서 회전은 ±10° 만 |
| ② **가중치 감쇠 (L2)** | `weight_decay 0.0005` | 가중치가 너무 커지지 않게 |
| ③ **드롭아웃** | **안 씀** (`dropout 0.0`) | CNN 탐지기는 배치 정규화 + 데이터 증대로 충분 (YOLO 기본) |
| (덤) 조기 종료 | 기준 점수가 오래 안 오르면 멈춤 · 우리는 30 에폭 고정 | |

- 해 보고 버린 증대: 잎 가림 합성 (나무 잎을 그려 넣기) — 숲은 구분 안 되고 한국 −0.5 %p 손해

### 2-6. 손실 함수 ★★★

| 강의 | 우리 |
|---|---|
| MSE 의 문제 (분류엔 부적합) | 박스 위치는 MSE 대신 **IoU 기반 손실 (CIoU)** — 박스가 겹친 정도를 직접 키움 |
| 교차 엔트로피 | 「사람이냐」 = **이진 교차 엔트로피 (BCE)** · 자세 로지스틱 = 교차 엔트로피 |
| (참고) | 손실 가중치: 박스 7.5 · 분류 0.5 · DFL 1.5 · 작은 물체용 손실 (NWD) 을 시도했지만 −2.4 %p 로 버림 |

## 4. 깊은 CNN 1 (05)

### 4-1. FC 의 한계 → 합성곱 ★★★

- 1280×736 컬러 영상을 FC 로 넣으면 입력이 280만 개 → 파라미터 폭발 · 위치가 조금만 바뀌어도 다르게 봄
- 합성곱 = **지역성** (작은 3×3 창) · **가중치 공유** (같은 필터를 화면 전체에) · **이동 등변성** (사람이 어디 있든 같은 필터로 찾음) → 화면 어디에 있든 사람을 찾는 탐지에 딱 맞음

### 4-2. 출력 크기 공식 ★★★ — 우리 숫자로 계산해 보기

> 출력 = ⌊(입력 + 2 × 패딩 − 커널) ÷ 보폭⌋ + 1

- YOLO11 의 다운샘플링 합성곱: 커널 3 · 패딩 1 · **보폭 2** → (1280 + 2 − 3) ÷ 2 + 1 = **640** (가로가 절반)
- 이걸 반복해 최종 특징 맵 3개 (보폭 8 · 16 · 32):
  - 1280×736 입력 → **160×92** · **80×46** · **40×23** 칸
  - 칸 하나 = 원래 화면 8 · 16 · 32 px
- 왜 1280×**736** 인가: 720 은 32 로 나눠지지 않아 32 의 배수인 736 으로 맞춤

### 4-3. 풀링 ★★★

- YOLO11 안의 **SPPF** (Spatial Pyramid Pooling-Fast) = **5×5 최대 풀링을 3번 연달아** → 작은 · 중간 · 큰 범위 특징을 한꺼번에 모음
- 다운샘플링은 대부분 풀링 대신 **보폭 2 합성곱**으로 함 (요즘 CNN 의 흔한 방식)

### 4-4. 수용 필드 · 큰 물체 vs 작은 물체 ★★★ — 우리 핵심 어려움

- 드론에서 사람은 **작다**: 운용 16~20 m 에서 키 50~100 px · 평가셋엔 24 px 미만이 21 %
- 보폭 8 칸 (8 px) 기준으로 24 px 사람 = 3칸 → 아주 작은 사람은 신호가 약함
- 대응: 1920×1080 을 줄이지 않고 **1280×720 조각 4장**으로 잘라 원래 크기 그대로 넣음 (통째로 줄이면 사람이 ⅔ 로 작아짐)
- 시도: 보폭 4 짜리 특징 맵을 더하는 「P2 머리」 → 우리 데이터에선 효과 없음 (±0)
- 결과: 데이터를 다시 짜서 작은 사람 (< 24 px) 재현율 **0.30 → 0.53**

### 4-5. Sequential vs 서브클래싱 · 함수형 API ★★★

- YOLO11 은 yaml 파일로 층을 쌓고 PyTorch `nn.Module` 서브클래싱으로 만든 모델 (분기 · 이어 붙이기 (concat) 가 많아 Sequential 로는 못 만듦 — 강의의 「언제 서브클래싱을 쓰나」 예)

## 5. 깊은 CNN 2 (06)

### 5-1. 배치 정규화 ★★★ — 우리 실제 사고 사례

- YOLO11 의 기본 블록 = **Conv → BN → SiLU** (강의 실습처럼 활성 함수 **앞에** BN)
- **사례 (09-27)**: 같은 설정으로 두 번 학습한 모델의 가중치를 평균 (「모델 수프」) 했더니 성능이 무너짐
  - 원인: 두 모델의 **BN 평균 · 분산 통계**가 서로 어긋나 평균 낸 값이 어느 쪽에도 안 맞음
  - BN 통계를 다시 계산해 살릴 수는 있었지만 박스가 넓어지는 부작용 → 채택 안 함
  - 지금 배포 모델은 **한 학습의 마지막 4 에폭 가중치 평균 (SWA)** — 같은 학습 안이라 BN 이 안 무너짐
- 시험 포인트: 학습 땐 배치 통계 · 추론 (eval) 땐 **이동 평균 통계** 를 씀 → eval() 을 안 부르면 결과가 달라짐

### 5-2. VGG — 3×3 쌓기 ★★★

- YOLO11 도 대부분 **3×3 합성곱** (7×7 한 층 = 3×3 세 층 · 파라미터 적고 비선형 더 많음)

### 5-3. ResNet — 잔차 학습 H(x) = F(x) + x ★★★

- YOLO11 의 **C3k2 블록** 안 Bottleneck 들이 **잔차 연결 (skip)** — 깊어도 기울기가 잘 흐름 (degradation 문제 해결)
- 사례: 모델을 키운 YOLO11**l** 은 오히려 −3~−8 % (우리 데이터 양에선 깊이 · 크기보다 데이터가 중요)

## 6. 전이 학습 · 물체 검출 (02 끝) ★★★

| 강의 | 우리 |
|---|---|
| 데이터가 적으면 미리 학습된 모델을 가져와 미세조정 | **COCO (일반 사진 데이터셋 · 80종 물체)** 로 미리 학습된 YOLO11m → 우리 드론 사람 데이터로 **전체 층 미세조정** (`freeze: null` · 동결 없음) |
| 앞단 = 직선 · 모서리 같은 공통 요소 | 앞단 필터는 드론 사진에도 그대로 유용 → 30 에폭만에 수렴 |
| 눈꽃 (freeze) / 불꽃 (fine-tune) | 우리는 전부 🔥 · (자세 실험에선 DINOv2 앞단 ❄ + 뒷단만 🔥 도 해 봄) |
| 분류 · **검출** · 분할 / R-CNN → YOLO | 우리는 **검출 (YOLO)** · 상의 색 계획에 **분할** (사람 · 옷 영역) 모델 후보 |
