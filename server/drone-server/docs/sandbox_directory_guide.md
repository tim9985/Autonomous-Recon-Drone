# 학교 서버 폴더 안내

현재 역할별 경로·파일 구조·운영 확인은 [파일 구조·운영 가이드 v1.2](server_file_structure_services_v1.2.md)를 따른다. 서버 최상위 README는 [트리 안내](sandbox_directory_readme.md)와 같다.

현재 실제 환경은 `drone-server`, `drone-dev`, `drone-real`이다. 날짜 이름의 이전 경로와 `drone-legacy` 바로가기는 제거했다. 기존 `directory-organization`의 복구 자료는 `drone-server/backups/maintenance`로 옮겼다.

공유 가능한 현재 검증 결과는 서버 `drone-server/evidence/maintenance`에, 관리자 전용 엔진 사본·DB 덤프·이전 설정은 `drone-server/backups/maintenance`에 보존한다. 당시 폴더 정리·경로 이관 기록은 역사적 자료이며 현재 경로 설명과 구분한다.
