이관 전 두 DB의 custom dump, 변경 전 설정 파일, 기존 컨테이너 정의를 `directory-organization/canonical-path-migration-20261009T122053Z/`에 root 전용 권한으로 보관했다. 컨테이너 정의에는 환경 값이 포함될 수 있으므로 외부에 공유하지 않는다. 원래 컨테이너는 새 경로에서 검증한 후 제거했다.
